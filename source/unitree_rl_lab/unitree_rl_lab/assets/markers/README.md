# Isaac Sim frame marker

`frame_prim.usd` is the standard Isaac Sim 5.0 XYZ frame marker used by
Isaac Lab's `FRAME_MARKER_CFG`. It is stored locally so GUI play does not wait
for the NVIDIA asset server.

Original asset URL:

`https://omniverse-content-production.s3-us-west-2.amazonaws.com/Assets/Isaac/5.0/Isaac/Props/UIElements/frame_prim.usd`

The USD is self-contained and has no external asset dependencies.
